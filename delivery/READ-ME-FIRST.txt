WHAT THIS IS
  A working, installable build of the app. It opens arena.ai/agent in a
  Chrome-backed Trusted Web Activity, with a Custom Tab fallback.

WHAT IT IS NOT
  - NOT signed with your release key.
  - NOT a Play Store submission.
  - NOT tested on any device. Nobody has installed it yet.

INSTALL
  1. Copy the APK to the phone (USB, Drive, whichever).
  2. Tap it. Allow "Install unknown apps" for whichever app is doing the
     installing (Files, Chrome, etc.).
  3. Play Protect will warn about an unknown developer. That is expected for
     any sideloaded app; choose "Install anyway".
  4. Open it.

EXPECT A URL BAR. arena.ai publishes an empty /.well-known/assetlinks.json,
so no app can claim a verified association with the domain. Full-screen needs
Arena to publish an asset statement.

VERIFY THE FILE FIRST (optional, needs a terminal)
  sha256sum -c SHA256SUMS.txt          ->  pankxu-1.0.0-debug.apk: OK

IMPORTANT BEFORE YOU LATER INSTALL A RELEASE BUILD
  This APK is signed with a throwaway debug key. A build signed with YOUR
  release key has the same package name but a different signer, so Android
  will refuse to install it over this one. Uninstall this first:
      adb uninstall what.thefcuk.pankxu
  or Settings -> Apps -> Pankxu -> Uninstall.
  You lose nothing: the app stores no data of its own.
