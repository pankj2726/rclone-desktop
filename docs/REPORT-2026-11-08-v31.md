## 2. What is not verified

This is the honest list. None of it can be tested without a phone, and no claim is made about it.

* **Install and launch.** The APK has never been installed. No device has ever opened it.
* **The launch gate.** The one-time research disclosure, the offline Retry screen and the
  browser hand-off for Google sign-in are compiled and lint-clean, never rendered.
* **PAR-01..PAR-12.** All twelve rows in `docs/COMPATIBILITY.md` are Unverified.
* **Negative tests N-01..N-10 and S-01..S-04.** Unverified, in `docs/QA-REPORT.md`.
* **Sign-in.** Neither Google nor email-OTP login has been attempted.
* **Release signing.** No release keystore exists; the APK is signed with the standard Android
  debug key, which any debug build on any machine can claim. `apksigner verify` was never run
  because there is no Android SDK here.
* **Key backup and restore (X-17/X-19), rotation (X-18).** Written as procedure, untested.
* **Link verification.** `https://arena.ai/.well-known/assetlinks.json` returned `{}` when it was
  last checked on 2026-11-08, so `autoVerify` stays off and the URL bar stays visible. The
  current state must be confirmed by you and by `pm get-app-links` on the device.
* **The real arena.ai entry URLs.** The four shortcuts were derived from public pages, not from
  a signed-in session. Until the capture exists, treat them as provisional.
