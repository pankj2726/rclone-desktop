## Permissions in the merged manifest (P6-07)

Exactly one entry:

```
what.thefcuk.pankxu.debug.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
```

This is a **signature-level permission the app defines for itself**, generated by `androidx.startup`
so its own dynamically-registered receivers cannot be targeted by other apps. It is not a device
capability, cannot be requested by anything else, and never produces a user prompt.

No `INTERNET`, no camera, no storage, no location. The docs were corrected to state this
precisely rather than the earlier blanket "no permissions at all".
