What to do with this value
  * Compare it against apksigner output before installing any release APK:
      apksigner verify --print-certs pankxu-1.0.0.apk | grep "SHA-256"
    The certificate digest must equal the line above. `app-release.apk` produced by
    `.github/workflows/release.yml` is checked against this file on every tag build, and
    the build fails if they differ.
  * Send it with the Arena permission request (docs/arena-permission-request.md); it is
    what an assetlinks.json entry has to match.
  * It is public by design. Do not put it in a file with anything secret.

What is NOT in this repository
  * the keystore file
  * the store and key passwords
  Both live outside the repository, in ./keys/ on the machine that generated them, and are
  mirrored into the repository secrets KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS and
  KEY_PASSWORD so CI can sign. Losing them means no future update can be signed with the
  same identity - see docs/KEY-MANAGEMENT.md for the rotation procedure.
